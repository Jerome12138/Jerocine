# 品牌中立化与配置化设计方案

> 目标：让任何人 clone 本仓库后，改少量几处即可部署为自己的影视站，代码内不固化任何人的品牌名。
> 状态：**方案稿（待评审）**，2026-09-17。

## 0. 问题

Jerocine 是站主个人品牌，却在公开仓库中被固化在 157 个文件里（tv 90 / web 44 / server 7 / deploy 6 / docs 等），且 `gf-` 设计令牌前缀（116 文件 + 94 文件 `gf_`）源于旧项目代号 "go film"。公开分享前需要：

1. **品牌名（显示层）** 与 **项目代号（内部标识）** 解耦；
2. 品牌名可配置（部署者改少量几处）；
3. `gf-` 前缀统一替换为中性前缀。

## 2. 设计原则：三层标识解耦

```
品牌层（显示，部署者必改）   → site_config(DB) + VITE_APP_TITLE(构建) + strings.xml(gradle 注入)
项目代号层（内部，中性固定） → 仓库名/容器名/服务名/包名/协议标识/默认域 —— 与任何品牌无关
设计令牌层（内部，中性固定） → gf- → 新前缀（跟随项目代号）
```

- **品牌层**：任何人部署后改后台 + 1~2 个构建文件即可，不改代码。
- **代号层**：对部署者透明（不影响品牌展示），但对"公开分享"必须中性化，否则仍是原作者的痕迹。
- **令牌层**：纯内部，全仓机械替换。

## 3. 品牌配置化补缺口

### 3.1 web（前端）
- `ManageSidebar.vue` 等处 `|| 'Jerocine'` fallback → 删除品牌字样（空串/中性）。
- `index.html` title + PWA manifest name → 用占位（如 `VITE_APP_TITLE` 变量），运行时由 site_config 覆盖 `document.title`（已有 getSiteConfig，补 title 同步）。
- `.env.production` / `.env.development` 默认值 → 中性（如项目代号名）。

### 3.2 APK（tv + web/android）
- `strings.xml app_name` → gradle 从 `gradle.properties`（或构建参数）注入，默认 = 项目代号名（中性）。
- `DEFAULT_SERVER_URL` → 删除硬编码 jerocine.art；首次启动引导输入服务器地址（tv 已有输入框逻辑，web/android 同理），可选 gradle 注入默认值（空）。
- 包名/命名空间：gradle 参数化（`applicationId` 与 `namespace` 读 gradle 属性），默认 = 中性代号包名。

### 3.3 文档与部署模板
- README / docs / deploy README / .env.example 中的品牌示例 → 占位符风格（`<你的站点名>` 或代号示例），并新增《品牌定制指南》：改哪几处、改哪里。
- LICENSE 版权行保留原作者（法律要求），与品牌无关。

## 4. 项目代号：选一个中性代号

需要选一个与品牌无关、短、全局唯一性好的代号，用于：仓库名（可选）、compose 项目名/容器名、包名、协议标识、令牌前缀词根。

候选（待用户定）：

| 候选 | 词根 | 令牌前缀 | 说明 |
|---|---|---|---|
| **cinebase** | cine | `cine-`/`cine_` | 影视语义，中性，不易冲突 |
| opencine | cine | `cine-` | 强调开源 |
| filmstack | fs | `fs-` | 影视栈 |
| moviehub | mh | `mh-` | 通用但略泛 |

推荐：**cinebase（前缀 `cine-`/`cine_`）**——短、语义清晰（影视）、与任何站主品牌无关、CSS 变量 `--cine-list-cols` 等读起来自然。

## 5. gf- 前缀替换（以 cine- 为例）

### 范围
- `gf-`：CSS 类名（`gf-card-grid`）、CSS 变量（`--gf-list-cols` / `--gf-dur-fast`）、data 属性（`data-gf-modal-open`）、sessionStorage 键（`gf-resume-prompted`）、日志前缀（`[gf-onerror]`）、web 全仓 116 文件。
- `gf_`：Android drawable 资源名（`gf_xxx` → `cine_xxx`），94 文件。
- 命名空间/class 名：tv 里可能还有 `GfXxx` 类？grep 确认（此前 server-state 说 drawable/id 等内部标识）。

### 方法
1. 全仓正则替换 `\bgf-` → `cine-`、`\bgf_` → `cine_`、`\bGf` → `Cine`（类名，如存在）、`\bGF` → `CINE`（常量，如存在）。
2. **耦合点同步**（JS 读 CSS 变量处必须同改，否则运行时报空）：
   - `web/src/composables/useGridRowsLimit.ts`（读 `--gf-list-cols`）
   - 所有 `data-gf-*` 读写的 vue 文件
   - sessionStorage 键读写（App.vue 等）
3. 验证：
   - `pnpm run build`（web）+ `pnpm exec vitest run`
   - `go build ./...`（server）
   - tv：全仓 grep 确认 `gf` 残留 0（Android 编译若本地无 SDK 则靠 grep + 服务器验证，或标注待验证）
4. 风险：中低。旧 storage 键/属性残留无害（会话级）；APK 旧版本与新版本键不一致无兼容问题（全部同版本升级）。

## 6. 部署者体验（最终目标清单）

公开分享后，部署者步骤（写入 README 快速开始）：

```
1. cp deploy/.env.example .env          # 填域名、密码、密钥路径
2. docker compose up -d                 # 起 mysql/redis → migrate → server → nginx
3. 后台设置：站点名、Logo、域名         # site_config，运行时生效
4. （可选）改 web/.env VITE_APP_TITLE   # 浏览器标签标题
5. （可选）打 APK：gradle.properties 注入应用名/包名/默认服务器
6. （可选）配置多采集源、广告过滤开关   # 已有能力
```

代码内**不再出现任何个人品牌**；默认值全部为中性代号或占位。
